# AI Student Analytics Platform 🎓

A full-stack, enterprise-grade application designed to analyze student data, predict academic performance, and provide intelligent insights through a unified dashboard.

## 🚀 Features
- **Unified Analytics Dashboard:** Comprehensive visual insights into student demographics, study habits, and academic performance.
- **AI Prediction Engine:** Advanced machine learning models to predict student outcomes based on various data points.
- **Global AI Assistant:** A floating chatbot integrated across the platform to answer data-driven queries instantly.

## 🛠️ Technology Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Python, FastAPI, Pandas, Scikit-Learn
- **Deployment & DevOps:** GitHub Actions, Azure Static Web Apps, Azure App Service (Planned)
